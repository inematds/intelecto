Como o INTELECTO foi construído de verdade

Os 5 passos reais

Não é teoria. É exatamente o que aconteceu para o INTELECTO sair do zero e funcionar no Telegram.

1
Passou o documento de referência
O arquivo my-framework-ingredients.md — gerado pela seleção de features na página de comparação — foi entregue ao Claude Code como ponto de partida. Esse documento descreve tudo que você quer que o assistente faça.
2
Pediu para gerar um plano
Uma instrução simples: "leia o documento e me dê um plano de como construir isso". O Claude leu tudo e devolveu uma estrutura de workstreams, arquivos, dependências e ordem de execução — antes de escrever uma linha de código.
3
O Claude fez perguntas durante o planejamento
Docker ou instalação direta? OpenRouter ou só Ollama? Qual modelo padrão? O Claude identificou os pontos que dependiam de decisão sua e perguntou antes de assumir. Você respondeu em português. Ele ajustou o plano.
4
Executou o plano
Com o plano aprovado, o Claude criou cada arquivo na ordem certa: config, segurança, providers, memória, canal Telegram, agent loop, wizard de setup e o launcher. Mostrou o que estava fazendo em tempo real e pediu confirmação antes de ações importantes.
5
Você copiou o .env e subiu o Docker
Uma ação só: copiar o arquivo .env com suas chaves de API (Telegram e OpenRouter) e rodar docker compose up. O assistente subiu, conectou no Telegram e começou a responder.

Passo a passo detalhado
1
Faça suas compras

Acesse a página de comparação de frameworks e escolha os ingredientes que fazem sentido para o seu dia a dia. Não precisa de conhecimento técnico — pense em funcionalidades.

Exemplos de escolhas
  • ✓  Canal de comunicação → Telegram
  • ✓  Memória → Guarda tudo que eu falar (SQLite)
  • ✓  Cérebro (IA) → OpenRouter — acesso a 100+ modelos
  • ✓  Rodar em → Docker (qualquer máquina)
  • ✓  Personalidade → Arquivos de texto editáveis
  • ✗  Não preciso → automação de browser, agendamento de tarefas
Ir para as compras →
2
Receba o documento de especificação

Com base nas suas escolhas, é gerado um arquivo — chamemos de meu-assistente.md — que descreve em detalhe o que precisa ser construído.

O que este arquivo contém
  • 📁  Quais arquivos criar e para que serve cada um
  • 🔗  Como as partes se conectam entre si
  • 📋  A ordem em que tudo deve ser construído
  • ⚙️  As configurações específicas das suas escolhas
  • 🔒  As regras de segurança que o Claude deve respeitar
💡

Você não escreve este arquivo

O documento é gerado automaticamente a partir das suas escolhas. Você só lê, revisa e aprova.

3
Abra o Claude Code

Coloque o documento gerado na pasta do projeto e abra o terminal nessa pasta.

# Navegue até a pasta do projeto
cd minha-pasta-do-projeto

# Abra o Claude Code
claude
📦

Precisa instalar o Claude Code?

Uma vez só: npm install -g @anthropic-ai/claude-code no terminal. Depois é só usar o comando claude.

4
Dê a instrução — uma frase

Dentro do Claude Code, você digita uma única frase. O documento já tem todo o detalhe — você só manda o Claude ler e construir.

A instrução que você digita

"Leia o arquivo meu-assistente.md e construa tudo que está descrito nele"

Só isso. O Claude Code lê o documento, entende o plano e começa a trabalhar.

O que acontece depois que você manda a instrução
  • 1. Claude lê o documento inteiro
  • 2. Cria os arquivos na ordem certa
  • 3. Te mostra o que está fazendo em tempo real
  • 4. Pede sua confirmação antes de ações importantes
  • 5. Avisa quando terminar
5
Ligue o assistente

Quando o Claude Code terminar, você liga o assistente com um comando.

Se você escolheu Docker
docker compose up
Se você escolheu instalação direta (Mac)
./start.sh

Abra o Telegram, mande uma mensagem para o seu bot. Ele responde.

6
Ajuste o que quiser

Se algo não ficou do jeito que queria, você fala em português mesmo, de volta no Claude Code.

Exemplos de pedidos de ajuste

"Quero que ele responda sempre em português"

"Muda a personalidade — quero que ele seja mais direto"

"Quero que ele lembre o nome das pessoas que me mandaram mensagem"

Não há limite de ajustes. É um processo contínuo de refinamento.

Perguntas frequentes
Preciso saber programar?

Não. Você escolhe o que quer em linguagem simples, o Claude Code escreve o código. Você testa e pede ajustes em português.

O que é o CLAUDE.md? Preciso criar?

O CLAUDE.md é um arquivo opcional que guarda as regras do projeto para o Claude não precisar ser relembrado toda vez. Ele é gerado automaticamente junto com o seu documento de especificação. Se não existir, você só precisa ser um pouco mais específico na sua instrução.

Qual a diferença entre o documento das compras e o que o Claude constrói?

O documento das compras é o plano — descreve o que você quer. O que o Claude constrói são os arquivos de código reais — o assistente funcionando de verdade.

E se o Claude errar algo?

Você descreve o problema em português e pede para corrigir. O Claude relê o código e conserta. Esse ciclo de correção é normal e esperado.
