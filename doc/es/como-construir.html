Cómo se construyó realmente INTELECTO

Los 5 pasos reales

No es teoría. Es exactamente lo que ocurrió para que INTELECTO partiera de cero y funcionara en Telegram.

1
Pasó el documento de referencia
El archivo my-framework-ingredients.md — generado mediante la selección de features en la página de comparación — se entregó a Claude Code como punto de partida. Ese documento describe todo lo que quieres que haga el asistente.
2
Pidió generar un plan
Una instrucción sencilla: "lee el documento y dame un plan para construir esto". Claude leyó todo y devolvió una estructura de workstreams, archivos, dependencias y orden de ejecución, antes de escribir una línea de código.
3
Claude hizo preguntas durante la planificación
¿Docker o instalación directa? ¿OpenRouter o solo Ollama? ¿Qué modelo predeterminado? Claude identificó los puntos que dependían de una decisión tuya y preguntó antes de asumir. Respondiste en portugués. Ajustó el plan.
4
Ejecutó el plan
Con el plan aprobado, Claude creó cada archivo en el orden correcto: config, seguridad, providers, memoria, canal de Telegram, agent loop, asistente de configuración y el launcher. Mostró en tiempo real lo que estaba haciendo y pidió confirmación antes de las acciones importantes.
5
Copiaste el .env y levantaste Docker
Una sola acción: copiar el archivo .env con tus claves de API (Telegram y OpenRouter) y ejecutarlo docker compose up. El asistente se inició, se conectó a Telegram y empezó a responder.

Paso a paso detallado
1
Haz tus compras

Ve a la página de comparación de frameworks y elige los ingredientes que tengan sentido para tu día a día. No necesitas conocimientos técnicos: piensa en funcionalidades.

Ejemplos de elecciones
  • ✓  Canal de comunicación → Telegram
  • ✓  Memoria → Guarda todo lo que digo (SQLite)
  • ✓  Cerebro (IA) → OpenRouter — acceso a 100+ modelos
  • ✓  Ejecutar en → Docker (cualquier máquina)
  • ✓  Personalidad → Archivos de texto editables
  • ✗  No lo necesito → automatización del navegador, programación de tareas
Ir a las compras →
2
Recibe el documento de especificación

Con base en tus elecciones, se genera un archivo; llamémoslo meu-assistente.md — que describe en detalle lo que se debe construir.

Qué contiene este archivo
  • 📁  Qué archivos crear y para qué sirve cada uno
  • 🔗  Cómo se conectan entre sí las partes
  • 📋  El orden en que se debe construir todo
  • ⚙️  Las configuraciones específicas de tus elecciones
  • 🔒  Las reglas de seguridad que Claude debe respetar
💡

No escribes este archivo

El documento se genera automáticamente a partir de tus elecciones. Solo tienes que leerlo, revisarlo y aprobarlo.

3
Abre Claude Code

Coloca el documento generado en la carpeta del proyecto y abre la terminal en esa carpeta.

# Navega hasta la carpeta del proyecto
cd minha-pasta-do-projeto

# Abre Claude Code
claude
📦

¿Necesitas instalar Claude Code?

Una sola vez: npm install -g @anthropic-ai/claude-code en la terminal. Después solo tienes que usar el comando claude.

4
Da la instrucción: una frase

Dentro de Claude Code, escribes una sola frase. El documento ya contiene todos los detalles: solo le pides a Claude que lo lea y lo construya.

La instrucción que escribes

"Lee el archivo meu-assistente.md y construye todo lo que está descrito en él"

Solo eso. Claude Code lee el documento, entiende el plan y empieza a trabajar.

Qué sucede después de que envías la instrucción
  • 1. Claude lee el documento completo
  • 2. Crea los archivos en el orden correcto
  • 3. Te muestra lo que está haciendo en tiempo real
  • 4. Te pide confirmación antes de realizar acciones importantes
  • 5. Te avisa cuando termina
5
Activa el asistente

Cuando Claude Code termine, activas el asistente con un comando.

Si elegiste Docker
docker compose up
Si elegiste la instalación directa (Mac)
./start.sh

Abre Telegram y envíale un mensaje a tu bot. Te responde.

6
Ajusta lo que quieras

Si algo no quedó como querías, se lo dices en portugués, de vuelta en Claude Code.

Ejemplos de solicitudes de ajuste

"Quiero que siempre responda en portugués"

"Cambia la personalidad: quiero que sea más directo"

"Quiero que recuerde los nombres de las personas que me enviaron mensajes"

No hay límite para los ajustes. Es un proceso continuo de perfeccionamiento.

Preguntas frecuentes
¿Necesito saber programar?

No. Tú eliges lo que quieres en lenguaje sencillo y Claude Code escribe el código. Tú lo pruebas y pides ajustes en portugués.

¿Qué es el CLAUDE.md? ¿Necesito crearlo?

CLAUDE.md es un archivo opcional que guarda las reglas del proyecto para que Claude no tenga que recibirlas de nuevo cada vez. Se genera automáticamente junto con tu documento de especificación. Si no existe, solo tienes que ser un poco más específico en tu instrucción.

¿Cuál es la diferencia entre el documento de compras y lo que Claude construye?

El documento de compras es el plan — describe lo que quieres. Lo que Claude construye son los archivos de código reales — el asistente funcionando de verdad.

¿Y si Claude se equivoca en algo?

Describes el problema en portugués y pides que lo corrija. Claude vuelve a leer el código y lo arregla. Este ciclo de corrección es normal y esperado.
